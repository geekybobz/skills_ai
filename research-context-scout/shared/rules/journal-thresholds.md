# Journal Thresholds

Use this rule after a real gap predicate exists. Do not use journal ambition to
create a gap. The threshold is a working target, not a promise of acceptance.

## Ladder

| Level | Working target | Required evidence |
|---|---|---|
| J0 | not paper-ready | no verified physics contribution or no clear gap |
| J1 | specialist Physical Review journal for the subfield (PRA, PRB, PRD, PRE, PRApplied) | high-quality, specific physics contribution with proper context |
| J2 | PRResearch style | significant physics-connected development beyond a narrow technical note |
| J3 | PRL style | concise result with impact, innovation, broad interest, and a claim statable in one sentence a non-specialist physicist can evaluate |
| J4 | PRX style | breakthrough, paradigm shift, major cross-field connection, or long-term field-level impact |

Pick the J1 journal from the project's subfield, not from habit. Start at J1 when
a real but narrow gap exists. Move up only after a new result survives the next
decisive test and strengthens the physical importance.

A `same-physics-same-math` relation forces J0 regardless of result quality: the
objective is already achieved. Reopen the ladder only if the project changes the
assumptions, regime or measurable outcome.

The per-level tests live in `journal-level-up.md`. Read it only when arguing
above the target you just assigned.

## Output contract

Record:

```text
current target:
why this target is realistic:
why the next higher target is not yet justified:
evidence needed to level up:
evidence that would force downgrade:
```
