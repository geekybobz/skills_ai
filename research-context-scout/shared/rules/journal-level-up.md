# Journal Level-Up Tests

Read only when arguing for a target above the one `journal-thresholds.md`
already assigned. A first orientation normally settles at J1 and never needs
this file.

Answer every question at a level before claiming the next one. An unanswered
question keeps the current target.

From J1 to J2:

- Does the result matter beyond one setup or numerical instance?
- Is there a clear physics message rather than only a method variant?
- Is the related work map strong enough to show the addition?

From J2 to J3:

- Can the result be stated as one sharp advance?
- Does it substantially advance a field, open an avenue, solve or step toward a
  critical problem, or introduce a high-impact method?
- Can a broad physicist understand the objective and importance from the first
  paragraph?

From J3 to J4:

- Does it define a landmark, paradigm shift, key cross-field connection, or
  long-term community tool/result?
- Is there enough substance for specialists while remaining meaningful to a
  broad physics audience?

A level-up argument never creates a gap. It only re-grades a gap the evidence
gate has already established.
