# Deepen Scout

Use after an initial orientation when the user supplies a new idea, answer,
derivation, result, constraint, source or corrected assumption.

Before loading by delta, verify that the physics objective,
existing-understanding ledger, relation map and gap verdict are populated. If
any is empty, run initial Cycle B first; then apply the supplied delta through
this phase. An invocation mode of `deepen` does not skip that unfinished
initial work.

## Load by delta

Read:

1. the compact active state and latest relevant cycle in
   `research-orientation.md`;
2. the newly named information; and
3. only prior sources needed to test affected claims, relation labels, or
   journal-threshold decisions.

Apply any supplied focus to lane selection and to the mathematical, numerical
or physical checks demanded by the delta.

Do not rerun the complete initial scan by default. Let

\[
S_{k+1}=\operatorname{revise}(S_k,\Delta_k),
\]

where \(S_k\) is the recorded project state and \(\Delta_k\) is the new
information.

## Classify and test the delta

| Delta | Required treatment |
|---|---|
| user idea | turn it into a precise, falsifiable claim |
| derivation | verify assumptions, steps, limits and counterexamples |
| numerical result | check objective, baseline, residuals and convergence |
| physical constraint | reopen feasibility and application mappings |
| source | map its problem, assumptions, method, result and difference |
| context correction | reopen the context mirror and every dependent search lane |
| search direction | revise only the affected clusters and acquisition manifest |
| acquired corpus | run pass-1 extraction on every new source before using it in synthesis |
| terminology mapping | test the equation, mechanism and achievement correspondence |
| corrected assumption | reopen every dependent conclusion |
| negative result | decide whether it rejects, bounds or redirects the claim |

Search more deeply than the initial pass around the changed claim only when it
can change the verdict. Seek support, counterevidence, no-go results and
adjacent formulations. Reapply the anti-hallucination rule, relation taxonomy,
evidence gate and journal ladder before strengthening a recommendation.

Load `rules/alignment-checkpoints.md`, `rules/literature-corpus.md` or
`rules/collective-synthesis.md` only when the delta reopens their gate. A newly
acquired paper cannot affect the orientation until its full text is extracted.
Rebuild only the affected collective idea and project-notation translation;
do not rerun or display every paper card.

If the user asks for mathematical tricks, control techniques, derivation
intuition, or method comparison, read `phases/math-method-lens.md`. That lens explains
methods and possible tricks but cannot override the physics objective,
existing-work verdict, or gap predicate.

## Interaction rule

Use the alignment-packet response actions for a user choice that would
materially change the deeper investigation. Write the packet to the record and
pause. When reasonable assumptions are harmless, record them and continue.

## Result review (G10)

After the delta is tested, close the cycle with a bounded orientation: stay on
the current direction, stop it, reproduce or benchmark the existing result,
adapt the direction, or level up the journal threshold. Record the supporting
evidence, uncertainty and gate before writing the brief; the user retains the
final research judgment.

## Update rule

Preserve user responses verbatim. Update only affected active-state entries,
existing-understanding entries, relation labels, claim evidence, application
mappings, gap verdict, journal threshold, paper direction and next validation.
Keep superseded conclusions visible with a short reason instead of silently
rewriting history.

Also update only the affected alignment state, search boundary, corpus count,
collective idea and project translation. A correction never silently preserves
a dependent conclusion.

Append `## Interaction cycle N`, where `N` is one more than the highest
existing cycle number. Repeat the cycle subsections and add a fresh user-response
marker pair whenever new questions require another user answer.

Stop when the brief states which idea survived, failed or remains speculative;
what evidence changed; whether the delta moved a claim from existing
understanding to new direction or the reverse; how applications or importance
changed; whether the paper threshold strengthened; and which next test has the
highest information value.
