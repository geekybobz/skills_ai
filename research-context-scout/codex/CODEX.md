# Codex Record and Tool Rules

- Resolve the project root before creating `research-orientation.md`.
- Treat every other project file as read-only unless the user separately asks
  for an edit.
- On the first initial cycle, write the reconstruction and one to three
  questions, report the record path, and stop for the user's answers.
- Never overwrite text between `USER RESPONSES START` and
  `USER RESPONSES END`.
- On continuation, patch compact state and append a numbered interaction cycle;
  do not rewrite the complete record.
- Browse only after project reconstruction and user intake. Cite primary
  sources near supported claims.
- Keep temporary extraction or test artifacts outside the research project.
