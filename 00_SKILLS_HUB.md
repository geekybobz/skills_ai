## Efficiency Rule

1. Match the task in [[01_TRIGGER_MAP]].
2. Read one family index under `index/`.
3. Read the family hub only if routing is still broad.
4. Load the final selected skill file.
5. Stop reading once the active skill is identified.

## Do Not

- Do not preload all design skills.
- Do not index packaged duplicates as canonical skills.
- Do not modify existing skill files unless the user explicitly asks.
