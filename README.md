# Skills AI

Obsidian-facing registry for local skills. Existing skill files stay in place;
the registry adds a connected routing layer for fast Codex/Claude lookup.

## Start

- Agent entry: [[SKILLS]]
- Main hub: [[00_SKILLS_HUB]]
- Trigger search: [[01_TRIGGER_MAP]]
- Load sequence: [[02_LOAD_ORDER]]

## Registry Principle

The registry stores only routing metadata:

- what the task looks like
- which family hub to read
- which specialized intro to read
- which exact skill file to load
- what write or script risk exists

It does not duplicate full skill instructions.
